# Projects

> Projetos orientados a problemas reais, organizados por conhecimento necessário.

Projetos são o ponto em que o leitor conecta conceitos, toma decisões e produz algo que pode ser revisado. Um projeto deve explicar contexto, público, objetivo, funcionalidades, requisitos, tecnologias sugeridas, critérios de conclusão, conhecimentos necessários e possíveis melhorias.

### [Advanced](./advanced/README.md)

Em desenvolvimento. Projetos avançados só serão adicionados quando os pré-requisitos, critérios técnicos e escopo puderem ser descritos com honestidade.

## Como concluir um projeto

Um projeto está concluído quando a primeira versão atende aos requisitos obrigatórios, possui instruções para executar, trata entradas previsíveis e registra limitações conhecidas. Extensões não são obrigatórias; elas servem para orientar o próximo ciclo de aprendizado.
