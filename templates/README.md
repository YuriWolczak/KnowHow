## Como usar

Copie o arquivo para a área adequada, renomeie usando inglês, lowercase e kebab-case e substitua todos os comentários. Remova seções que não fizerem sentido, mas não mantenha placeholders no conteúdo publicado.

Cada novo arquivo deve ser revisado quanto a clareza, links relativos, exemplos e referências antes de ser proposto.
