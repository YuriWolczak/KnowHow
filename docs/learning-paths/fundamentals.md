# Trilha de fundamentos

> Percurso recomendado para quem está começando do zero em programação.

Esta trilha reduz saltos de conhecimento, mas não impede a consulta independente. Leia cada assunto, faça anotações com suas próprias palavras e pratique antes de avançar.

## Percurso

| Etapa | Assunto | Depois de estudar |
| ---: | --- | --- |
| 1 | [O que é programação?](../../fundamentals/what-is-programming.md) | Você consegue explicar o que é uma instrução e por que programar envolve resolver problemas. |
| 2 | [Como computadores executam instruções](../../fundamentals/how-computers-execute-instructions.md) | Você entende a diferença entre código, programa em execução, memória e entrada/saída. |
| 3 | [Algoritmos](../../fundamentals/algorithms.md) | Você consegue descrever uma solução como passos finitos e verificáveis. |
| 4 | [Lógica de programação](../../fundamentals/programming-logic.md) | Você consegue decompor uma decisão e representar regras com clareza. |
| 5 | [Variáveis e tipos de dados](../../fundamentals/variables-and-data-types.md) | Você consegue nomear dados e distinguir categorias básicas de valores. |
| 6 | [Operadores, entrada e saída](../../fundamentals/operators-input-output.md) | Você consegue receber dados, transformá-los e apresentar um resultado. |
| 7 | [Condicionais](../../fundamentals/conditionals.md) | Você consegue executar caminhos diferentes conforme uma condição. |
| 8 | [Loops](../../fundamentals/loops.md) | Você consegue repetir uma ação com uma condição de parada explícita. |
| 9 | [Funções](../../fundamentals/functions.md) | Você consegue organizar uma solução em partes reutilizáveis. |
| 10 | [Estruturas de dados](../../fundamentals/data-structures.md) | Você consegue escolher uma forma adequada de agrupar valores. |
| 11 | [Introdução à orientação a objetos](../../fundamentals/object-oriented-programming.md) | Você reconhece quando estado e comportamento podem ser modelados juntos. |
| 12 | [Algoritmos e complexidade](../../fundamentals/algorithms-and-complexity.md) | Você começa a comparar soluções pelo custo de tempo e memória. |
| 13 | [Introdução a Git](../../technologies/git/README.md) | Você consegue registrar mudanças e recuperar versões do seu trabalho. |

## Aplicação

Depois das etapas iniciais, escolha uma trilha específica. Os fundamentos são compartilhados; cada percurso abaixo ensina a sintaxe, as ferramentas e as decisões próprias de seu ecossistema:

| Trilha | Foco inicial |
| --- | --- |
| [C](../../languages/c/README.md) | Fundamentos da linguagem, compilação, memória e programação procedural |
| [Java](../../languages/java/README.md) | Sintaxe, tipos, classes, objetos e ferramentas do JDK |
| [Python](../../languages/python/README.md) | Sintaxe expressiva, coleções, funções e automação |
| [Web](../../languages/web/README.md) | HTML para estrutura, CSS para apresentação e JavaScript para comportamento |

Para consolidar qualquer trilha, resolva os [exercícios básicos](../../exercises/README.md) e escolha um [projeto iniciante](../../projects/beginner/README.md).

## Como saber se pode avançar?

Você não precisa memorizar todos os comandos. Avance quando conseguir explicar a ideia, escrever uma solução simples sem copiar e investigar um erro básico. Se ainda houver confusão, retorne ao conceito anterior e tente um exercício menor.
