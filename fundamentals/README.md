# Fundamentals

> Conceitos de programação e desenvolvimento de software que não dependem exclusivamente de uma linguagem.

Esta seção é a base conceitual da Knowledge Base. Ela foi pensada para quem está começando e precisa entender os modelos mentais antes de escolher ferramentas ou frameworks.

## Trilha inicial

Siga a ordem recomendada abaixo. Os assuntos são independentes o bastante para consulta, mas a sequência reduz saltos de conhecimento:

2. [Como computadores executam instruções](./how-computers-execute-instructions.md)
3. [Algoritmos](./algorithms.md)
4. [Lógica de programação](./programming-logic.md)
5. [Variáveis e tipos de dados](./variables-and-data-types.md)
6. [Operadores, entrada e saída](./operators-input-output.md)
7. [Condicionais](./conditionals.md)
8. [Loops](./loops.md)

11. [Introdução à orientação a objetos](./object-oriented-programming.md)

## O que ainda será desenvolvido?

Os seguintes assuntos fazem parte do escopo, mas só devem ser ampliados quando houver explicações e exemplos revisados:

- bancos de dados e modelagem;
- redes;
- sistemas operacionais;
- engenharia de software;
- arquitetura de software;
- APIs;
- segurança.

A ausência de uma página não é um convite para criar conteúdo superficial. Quando uma nova área for iniciada, ela deve ter um objetivo claro, pré-requisitos, exemplos e conexões com exercícios ou projetos.

## Como estudar

Leia o conceito, tente explicar com suas próprias palavras, execute ou adapte os exemplos e resolva os exercícios relacionados. Depois, avance para um desafio ou projeto. A [trilha completa para iniciantes](../docs/learning-paths/fundamentals.md) mostra como esses conteúdos se conectam a Python e Git.
