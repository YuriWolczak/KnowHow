# Exercícios de lógica de programação

> Problemas independentes de linguagem para praticar raciocínio antes de escolher uma sintaxe.

Estes exercícios pertencem a `fundamentals/` porque treinam ideias que continuam válidas em C, Java, Python, JavaScript e outras linguagens. Tente resolver primeiro em pseudocódigo ou fluxograma; depois implemente o mesmo algoritmo na linguagem que estiver estudando.

## Progressão sugerida

| Ordem | Exercício | Conceitos principais |
| ---: | --- | --- |
| 1 | [Soma dos algarismos](./sum-of-digits.md) | Repetição, divisão inteira e resto |
| 2 | [FizzBuzz com regras explícitas](./fizzbuzz.md) | Condicionais e ordem de regras |
| 3 | [Palíndromo](./palindrome.md) | Strings, comparação e normalização |
| 4 | [Número primo](./prime-number.md) | Repetição, divisibilidade e complexidade |

## Como usar

Cada problema informa objetivo, entrada, saída, exemplos, restrições e dicas. A solução de referência usa pseudocódigo para preservar a independência de linguagem. Depois da tentativa, implemente o algoritmo em [C](../../languages/c/README.md), [Java](../../languages/java/README.md), [Python](../../languages/python/README.md) ou [Web/JavaScript](../../languages/web/javascript/README.md).
