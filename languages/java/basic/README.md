Estude antes a [trilha de fundamentos](../../../docs/learning-paths/fundamentals.md). Esta seção não repete a lógica de algoritmos; mostra como expressá-la em Java e como usar as ferramentas básicas do JDK.

## Escopo da primeira versão

Os exemplos usam a API Java SE e devem declarar quando dependerem de uma versão específica. O JDK fornece ferramentas de desenvolvimento; uma instalação disponível e os comandos `javac` e `java` podem depender da configuração do sistema.

## Exemplos executáveis

Os exemplos independentes de interação em [`examples/java/`](../../../examples/README.md) são compilados com JDK 21 e executados pelo GitHub Actions. Eles mostram soma de algarismos, número primo e FizzBuzz.
