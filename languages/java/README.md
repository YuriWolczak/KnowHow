# Java

> Trilha para aprender Java, sua sintaxe, seu modelo de tipos, orientação a objetos e ferramentas do JDK.

Java será estudado depois dos [fundamentos independentes de linguagem](../../fundamentals/README.md). A trilha deve mostrar como a mesma lógica geral é expressa em Java e quais conceitos são próprios do ecossistema.

## Trilha

### Basic

- [Fundamentos de Java](./basic/README.md)

### Intermediate

Em desenvolvimento. Os próximos assuntos previstos incluem coleções, exceções, interfaces, generics, testes, build e organização de aplicações.

### Advanced

Em desenvolvimento. Conteúdos avançados deverão tratar concorrência, JVM, performance, modularidade, redes e arquitetura com versões e contexto declarados.
