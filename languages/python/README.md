# Python

> Primeira linguagem prática da Knowledge Base, escolhida para aplicar fundamentos com uma sintaxe acessível e uma biblioteca padrão ampla.

## Visão geral

Python é uma linguagem de programação de propósito geral. Nesta base, ela será usada para transformar conceitos de fundamentos em programas pequenos, legíveis e testáveis. A trilha não pretende ensinar apenas sintaxe: cada assunto deve explicar o que muda em relação ao conceito geral e por que uma construção é útil.

Consulte a [documentação oficial do Python](https://docs.python.org/3/) para detalhes completos da linguagem e da biblioteca padrão.

## Pré-requisito recomendado

Comece pela [trilha de fundamentos](../../docs/learning-paths/fundamentals.md). É possível consultar Python diretamente, mas entender variáveis, condicionais, loops, funções e estruturas de dados torna o percurso mais proveitoso.
