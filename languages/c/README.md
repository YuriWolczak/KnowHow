# C

> Trilha para aprender C e observar de perto compilação, tipos, memória e programação procedural.

C será estudado depois dos [fundamentos independentes de linguagem](../../fundamentals/README.md). A trilha deve explicar o que é específico de C sem repetir a lógica geral de condicionais, loops, funções e algoritmos.

## Trilha

### Basic

- [Fundamentos de C](./basic/README.md)

### Intermediate

Em desenvolvimento. Os próximos assuntos previstos incluem ponteiros com mais profundidade, alocação dinâmica, estruturas, arquivos, modularização e ferramentas de compilação.

### Advanced

Em desenvolvimento. Conteúdos avançados deverão tratar portabilidade, desempenho, concorrência, segurança de memória e detalhes do padrão com contexto explícito.
