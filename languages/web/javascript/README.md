# JavaScript

> Linguagem de programação usada na Web para adicionar comportamento e interação às páginas.

JavaScript é diferente de HTML e CSS: ele permite expressar lógica, reagir a eventos e alterar o estado de uma página. Nesta trilha, os exemplos partem de HTML e CSS existentes para preservar a separação de responsabilidades.
