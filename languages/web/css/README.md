# CSS

> Linguagem de estilos que define apresentação, espaçamento, layout e adaptação visual de documentos HTML.

CSS não substitui a estrutura do HTML. Ele aplica regras de apresentação ao documento e permite criar layouts que respondem a diferentes tamanhos de tela.
