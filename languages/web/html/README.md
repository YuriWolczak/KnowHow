# HTML

> Linguagem de marcação que estrutura e dá significado ao conteúdo de uma página Web.

HTML não é uma linguagem de programação. Ele descreve elementos, relações e semântica do documento. A trilha Web usa HTML como primeiro passo porque CSS e JavaScript dependem de uma estrutura que o navegador possa interpretar.

## Relação com as outras partes da Web

HTML define conteúdo e estrutura. [CSS](../css/README.md) cuida de apresentação e layout. [JavaScript](../javascript/README.md) cuida de comportamento e interação. Misturar essas responsabilidades sem necessidade torna a página mais difícil de manter e testar.
