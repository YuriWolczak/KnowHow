# Web

> Trilha do desenvolvimento para a Web, organizada por estrutura, apresentação e comportamento.

A Web não é uma única linguagem. Nesta Knowledge Base, ela é uma trilha de ecossistema composta principalmente por **HTML**, **CSS** e **JavaScript**. HTML estrutura e dá significado ao conteúdo; CSS define apresentação e layout; JavaScript adiciona comportamento programável. Separar essas responsabilidades ajuda a entender o que cada tecnologia resolve.

## Ordem recomendada

| Ordem | Parte | Responsabilidade | Entrada |
| ---: | --- | --- | --- |
| 1 | [HTML](./html/README.md) | Estrutura e semântica do documento | Elementos, atributos, links, imagens e formulários |
| 2 | [CSS](./css/README.md) | Apresentação, layout e responsividade | Seletores, cascata, box model e layout |
| 3 | [JavaScript](./javascript/README.md) | Comportamento e interação | Sintaxe, DOM, eventos e módulos |

A trilha Web também dependerá de fundamentos de acessibilidade, redes, HTTP e Git conforme avançar. Esses conceitos gerais devem continuar em suas próprias áreas quando não forem específicos de HTML, CSS ou JavaScript.
