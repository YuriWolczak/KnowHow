## Como usar

Consulte um recurso depois de entender o conceito principal. Um cheatsheet ajuda a lembrar uma forma de escrever algo; ele não deve ser o primeiro contato com um assunto complexo.

Links para documentação externa devem apontar preferencialmente para a fonte oficial, registrar o assunto consultado e evitar afirmar que uma versão antiga é universal.
