# Cheatsheets

> Resumos para consulta rápida depois que o conceito já foi estudado.

Esta área está em desenvolvimento. Um cheatsheet deve ser curto, correto, organizado por tarefa e acompanhado de contexto suficiente para não induzir uso incorreto.

Quando o primeiro cheatsheet for criado, inclua versão ou contexto da ferramenta e links para a explicação completa e a documentação oficial.
