# Glossary

> Definições curtas de termos técnicos usados na Knowledge Base.

O glossário é uma referência rápida, não um substituto para os tutoriais. Cada definição deve explicar o termo em linguagem simples e, quando ajudar, incluir uma analogia curta. Conceitos complexos devem apontar para uma explicação completa.

## Termos iniciais

### API

Uma **API** (*Application Programming Interface*) é uma interface com regras que permite que sistemas ou partes de um sistema se comuniquem. A API define como pedir algo e qual formato de resposta esperar; ela não é necessariamente uma aplicação visual.

### Algoritmo

Um **algoritmo** é uma sequência finita e organizada de passos para resolver um problema ou produzir um resultado. Uma receita de cozinha é uma analogia útil, mas um algoritmo precisa lidar com entradas, regras e casos possíveis de forma precisa.

### Branch

Uma **branch** é uma linha de desenvolvimento separada dentro de um repositório Git. Ela permite trabalhar em uma mudança sem alterar diretamente a linha principal.

### Commit

Um **commit** é um registro nomeado de alterações preparadas no Git. Ele funciona como um ponto do histórico que pode ser comparado, consultado e, em determinados fluxos, revertido.

### Terminal

O **terminal** é um programa que permite interagir com o sistema por meio de comandos de texto. O comando é uma instrução escrita para uma ferramenta; seu efeito depende do diretório, dos argumentos e do ambiente.

### Variável

Uma **variável** é um nome associado a um valor que um programa pode consultar e, dependendo da linguagem, atualizar. O nome ajuda a comunicar o significado do dado além de sua representação imediata.
