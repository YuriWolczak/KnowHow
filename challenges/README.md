# Challenges

> Problemas integradores para desenvolver autonomia, tomada de decisão e capacidade de investigar.

Desafios combinam mais de um conceito e deixam espaço para escolhas. O enunciado deve explicar contexto, requisitos funcionais e técnicos, restrições, critérios de conclusão e extensões opcionais. A solução completa não deve eliminar a oportunidade de raciocinar.

## Desafios disponíveis

## Antes de começar

Leia os pré-requisitos e defina uma primeira versão pequena. Divida o trabalho em partes, registre decisões e teste cada comportamento. Uma implementação concluída não precisa conter todas as extensões opcionais.

Use o [template de desafio](../templates/challenge.md) para propor novos problemas e conecte-os a exercícios, fundamentos, tecnologias e projetos relacionados.
