# Technologies

> Ferramentas, plataformas, frameworks e ecossistemas usados para construir e manter software.

Tecnologias resolvem problemas específicos, mas não substituem fundamentos. Cada página deve explicar o problema resolvido, pré-requisitos, instalação, configuração, conceitos essenciais, exemplos, erros comuns, boas práticas e referências oficiais.

## Como uma tecnologia entra nesta seção?

A tecnologia deve ser estudada dentro de um contexto: qual problema ela resolve, quais alternativas existem e quando não vale a pena utilizá-la. Comandos devem ser testados no contexto indicado e acompanhados de uma explicação do efeito produzido.

Versões e comportamentos que possam mudar devem ser identificados. Quando existir documentação oficial, ela deve ser a principal referência.
